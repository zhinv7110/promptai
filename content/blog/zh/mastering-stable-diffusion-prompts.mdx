## 超越基础提示词

Stable Diffusion 让你对图像生成拥有惊人的控制力。掌握基础之后，这些高级技巧将帮助你精确实现你想要的画面。

## 提示词权重

使用括号强调词汇，方括号减弱权重：

```
(美丽精致的眼睛:1.3), (精细盔甲:1.2), [简单背景:0.5]
```

权重大于1.0增强重要性，小于1.0降低。

## 风格混合

通过权重混合风格获得独特效果：

```
[动漫:数字绘画:0.3], 赛博朋克夜晚城市, 霓虹倒影, 8K
```

## 反向提示词的力量

一个强大的反向提示词至关重要。这是一个模板：

```
丑陋的, 变形的, 模糊的, 低质量的, 水印, 文字, 糟糕的人体结构, 多余的肢体, 画得不好的脸部, 毁容的, JPEG伪影
```

## Token 效率

SD 有约75个 token 的软限制。每个词都很重要。优先级：

1. 主题描述
2. 风格与媒介
3. 光线与氛围
4. 技术质量
5. 构图

## 高级关键词

- **摄影**: `35mm`、`光圈f/1.4`、`背景虚化`、`微距镜头`
- **艺术**: `artstation热门`、`概念艺术`、`数字绘景`
- **光线**: `上帝光`、`轮廓光`、`体积雾`、`环境光遮蔽`
- **材质**: `次表面散射`、`金属光泽`、`粗糙纹理`
