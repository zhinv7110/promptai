## 为什么提示词很重要

Midjourney、Stable Diffusion 和 DALL-E 等 AI 图像生成器是强大的工具，但它们需要指引。精心制作的提示词是平庸结果与杰作之间的区别。

把提示词想象成与 AI 的对话。你越具体、描述性越强，它就越能理解你想要什么。

## 基本提示词结构

一个好的提示词通常包括：

1. **主题** — 主要内容是什么？
2. **风格** — 艺术风格、媒介或美学
3. **光线** — 场景如何打光
4. **构图** — 镜头角度、画框、焦距
5. **质量** — 分辨率、细节水平、渲染质量

### 示例拆解

**基础提示词：**
```
一只坐在窗台上的猫
```

**增强后的提示词：**
```
一只蓬松的橘色虎斑猫在阳光洒落的木制窗台上安睡，金色时刻的光线透过蕾丝窗帘洒入，浅景深，85mm镜头，舒适小屋氛围，写实风格，8K，编辑摄影风格
```

## 好用的风格关键词

- **写实**：8K、超写实、清晰对焦、细节丰富
- **电影感**：胶片颗粒、变形镜头、调色
- **动漫**：吉卜力风格、赛璐珞着色、2D动画
- **艺术**：油画、水彩、素描、概念艺术
- **暗黑/氛围**：低色调、戏剧阴影、黑色电影

## 常见错误

1. **过于模糊** — "美丽的风景"对AI来说毫无意义
2. **过于复杂** — 不要把50个形容词塞进一句话
3. **忽略反向提示词** — 告诉AI你**不**想要什么
4. **错误的宽高比** — 始终根据用途指定尺寸
